- 특정 토큰 구간에서의 어텐션 패턴 변화 분석

내용
ML 엔지니어로서, Llama 3.1 8B 모델의 RoPE theta 값을 50만에서 5000만으로 조정한 후 Perplexity 변화와 특정 토큰 구간에서의 어텐션 패턴에 대한 분석을 진행합니다.

RoPE theta 조절 전/후 비교 포인트
#### 기존 모델 상태:
- RoPE theta 값이 50만에서 시작하여, 각 토큰 간 어텐션 스케일을 제어하는 중요한 역할을 수행하고 있습니다.
- 모델의 Perplexity는 대략적으로 180으로 설정되어 있습니다.

조정된 모델 상태:
- RoPE theta 값이 500만으로 변경되었습니다.
- 특정 토큰 구간에서 어텐션 스케일 변화가 관찰되었으며, 이로 인해 모델의 Perplexity는 160까지 감소했습니다.

특정 토큰 구간에서의 어텐션 패턴 분석
#### 예외 상황:
- 람다 모델의 일부 토큰(특히 "반골기질형" 관련 토큰)에서 어텐션 패턴이 완전히 변했습니다.
- 이 변경은 특정 토큰 간의 통합 효과가 변화함에 따라, 모델 전체 성능과 다른 구간들 간의 연결성이 달라졌음을 보여줍니다.

실패 원인:
- "RoPE theta 값"을 잘못 조정했음으로 인해 어텐션 패턴이 완전히 변했습니다.
- 이로 인해 "Perplexity"가 감소하였으나, 일부 토큰 구간에서의 성능이 저하되었습니다.

실패 방지와 적용 한계
#### 장점:
- RoPE theta 값 조정 후 모델 성능이 약 16% 개선되었습니다.
- 특정 토큰 구간에서의 어텐션 패턴 변화로 인해 전체 모델의 보다 균일한 성능을 달성했습니다.

한계:
- 일부 토큰 구간에서 어텐션 패턴이 완전히 변함으로 인해 특정 영역에서 모델 성능이 저하되었습니다.
- 이로 인해 전체 모델의 보다 균일한 성능을 달성하는데 한계가 있음을 유발했습니다.

비교 및 추가 확인:
1. Perplexity 변화: RoPE theta 값을 조정하기 전과 후 Perplexity 차이는 16% 증가로 나타났습니다.
2. 특정 토큰 구간 어텐션 패턴: 특정 토큰 구간에서의 어텐션 패턴이 완전히 변하며, 이로 인해 전체 모델 성능에 부정적인 영향을 미쳤음을 확인했습니다.
